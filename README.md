# 🔥 BLITZ Userbot (Personal Edition)

ဒီ Bot ကတော့ သားကြီးရဲ့ ကိုယ်ပိုင် Telegram Account မှာ အသုံးပြုဖို့အတွက် ဖန်တီးထားတဲ့ **Powerful Userbot** ဖြစ်ပါတယ်။ ကိုယ်တိုင် စာပြန်စရာမလိုဘဲ လူလိုအော်တိုပြန်ပေးမယ့်စနစ် (Auto-Reply) နဲ့ အခြား အသုံးဝင်တဲ့ Tool ပေါင်းများစွာ ပါဝင်ပါတယ်။

## 🚀 Features (အဓိက လုပ်ဆောင်ချက်များ)

| Command | Description |
| :--- | :--- |
| **Auto-Reply** | Keyword အလိုက် သားကြီးကိုယ်တိုင် ပြန်သလိုမျိုး အော်တိုစာပြန်ပေးခြင်း။ |
| `.id` | ကိုယ့် ID ဒါမှမဟုတ် တစ်ဖက်လူရဲ့ ID ကို စစ်ဆေးခြင်း။ |
| `.song` | YouTube ကနေ သီချင်းနာမည်နဲ့ ရှာဖွေခြင်း။ |
| `.tt` | TikTok Video ကို Logo မပါဘဲ ဒေါင်းလုဒ်ဆွဲခြင်း။ |
| `.block` | နှောင့်ယှက်သူများကို ချက်ချင်း Block ခြင်း။ |
| `.bc` | User များအားလုံးထံ ကြေညာချက်တစ်ပြိုင်နက် ပို့ခြင်း (Broadcaster)။ |
